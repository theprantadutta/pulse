# Data assets

- `oui.tsv.gz` — MAC vendor prefixes (MA-L/MA-M/MA-S) extracted from the IEEE registry via Wireshark's `manuf` file (https://www.wireshark.org/download/automated/data/manuf). Regenerate occasionally; format is `HEXPREFIX<TAB>Vendor` per line, gzip-compressed.
- `world_map.bin` — offline vector world map for Geo IP: land polygons and country borders from Natural Earth 1:50m (public domain), via the world-atlas TopoJSON package `countries-50m.json` (ISC, https://github.com/topojson/world-atlas). Format: `'PWM1'`, u32 land rings, u32 border lines, then per record a u32 point count and `(i16 lon, i16 lat)` pairs scaled by 32767/200 and 32767/90 (little endian). Rings crossing the antimeridian are unwrapped (lon may exceed 180; Antarctica is closed through the pole). Borders are the arcs shared by two countries; coastlines are just the land fill edge.
